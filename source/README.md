# source/

The LabVIEW toolkit, as one library: `RemoteVI.lvlib`, saved for LabVIEW 2020 (opens in 2020 and every newer version). Its virtual folders mirror the disk folders.

```
source/
├── RemoteVI.lvlib   the library; every member is public, but only API/ is the supported interface
├── API/             RemoteVI Start.vi, RemoteVI Stop.vi             <- put these in your application
├── Server/          server loop, connections, clients, frames, overlay, embedded web client
├── Capture/         panel capture, dirty rects, PNG encode
├── Protocol/        frame/overlay encode, input parser, WebSocket framing (pure, vector-tested)
├── Input/           translate and post window messages, modifiers, popups/submenus
└── Win32/           user32/gdi32/kernel32 wrappers (generated by scripts/Build Win32 Wrappers.vi)
                     and the composite Win32 VIs built on them
```

The other members are public only so the tests, the fixture and the benchmarks can call them directly. They may change without notice.

Most VIs are generated from AIXML in `tools/aixml/`. A regenerated VI loses its library membership, so re-add it (see docs/architecture.md). The project's `source` folder is auto-populating, so new files show up in `RemoteVI.lvproj` on their own.
